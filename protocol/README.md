# Kule Protocol

The versioned communication contract shared by the Hub and host agents.

The protocol will define authenticated enrollment and handshake, typed request and reply messages, request correlation, timeouts, compatibility negotiation, reconnection and revocation behavior. The Kule Hub will issue and validate enrollment identities; no hosted third-party Hub will participate in authentication.

The dedicated protocol package is in development.

See the [architecture](../docs/architecture/host-control-monorepo.md).
